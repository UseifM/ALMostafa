## 🎨 الهوية البصرية والتصميم (Visual Identity)

- **الألوان الأساسية:**
  - الأزرق الكحلي الداكن الفاخر (`#070e1b`, `#0b192c`, `#142a4a`)
  - لمسات ذهبية قانونية راقية (`#c5a059`, `#d4af57`, `#ecdcb1`)
  - خلفيات ناصعة ومريحة للقراءة (`#ffffff`, `#f8fafc`)
- **الخطوط:** الخطوط العربية المعتمدة من Google Fonts (`Cairo` للنصوص والعناوين، و `Amiri` للعبارات والأختام القانونية).
- **التصميم المتجاوب (Responsive):** متوافق بنسبة 100% مع أجهزة الكمبيوتر المكتبية، الحواسيب المحمولة، الأجهزة اللوحية (Tablets)، والهواتف الذكية.
- **الاتجاه:** يدعم الكتابة والواجهة من اليمين إلى اليسار (RTL) بشكل أصيل ودقيق.

## 🛠️ دليل تخصيص واستبدال الملفات (Customization Guide)

### 1. استبدال شعار المكتب (Logo)
ضع ملف الشعار الخاص بك بصيغة PNG أو SVG داخل مجلد `assets/` بالاسم التالي:
```text
assets/logo.png
```
*الأبعاد الموصى بها: 500×500 بكسل أو بخلفية شفافة.*

---

### 2. استبدال صورة الأستاذ يوسف مصطفى ضاهر
استبدل الملف في المسار:
```text
assets/youssef-mostafa.jpg
```
*الأبعاد الموصى بها: نسبة 4:5 (مثال: 600×750 بكسل أو 800×1000 بكسل).*

---

### 3. استبدال الكلمة الصوتية (Voice Audio)
قم بوضع التسجيل الصوتي الخاص بكلمة الأستاذ يوسف مصطفى ضاهر في المسار:
```text
assets/youssef-voice.mp3
```
*المشغل الصوتي المخصص في الموقع يدعم التشغيل، الإيقاف، شريط التقدم التفاعلي، التحكم بمستوى الصوت، والموجات الصوتية المتحركة.*

---

### 4. إضافة أعضاء جدد إلى قسم «فريقنا»
في ملف `index.html`، انتقل إلى القسم `<section id="team">` وستجد تعليقاً واضحاً يوضح كيفية نسخ بطاقة العضو:

```html
<!-- بطاقة عضو فريق جديد -->
<div class="team-card reveal">
  <div class="team-photo-wrapper">
    <img src="assets/team-member-1.jpg" alt="اسم العضو" class="team-photo">
  </div>
  <div class="team-info">
    <h3 class="team-name">اسم المستشار القانوني</h3>
    <p class="team-role">المسمى الوظيفي</p>
    <p class="team-bio">نبذة مختصرة عن التخصص القانوني والمهام.</p>
  </div>
</div>
```

### 5. ربط نموذج الاستشارة بقاعدة بيانات أو بريد إلكتروني (Backend API Hook)
في ملف `script.js` داخل دالة إرسال النموذج `form.addEventListener('submit', ...)`. ستجد خطافاً برمجياً واضحاً لاستبدال المحاكاة التجريبية بطلب اتصال حقيقي:

```javascript
// استبدل setTimeout بـ fetch أو خدمة EmailJS:
fetch('https://your-api-endpoint.com/api/consultation', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    fullName: fullNameInput.value,
    email: emailInput.value,
    phone: phoneInput.value,
    consultationType: consultationTypeSelect.value,
    details: detailsTextarea.value
  })
})
.then(response => response.json())
.then(data => {
  // إظهار نافذة التأكيد
})
.catch(error => {
  console.error('خطأ في الإرسال:', error);
});
```

*ميزة إضافية مدمجة:* عند إرسال النموذج، توفر نافذة التأكيد زراً مباشراً للمستخدم لإرسال نسخة من بيانات استشارته فوراً عبر **واتساب** إلى الرقم `01023838513`.
